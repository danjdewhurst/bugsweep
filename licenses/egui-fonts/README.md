# Fonts in the bugsweep binary

The desktop window (`bugsweep gui`) uses the default fonts of
[egui](https://github.com/emilk/egui). They come from the crate
`epaint_default_fonts` and are built into the binary.

| Font | Licence |
|---|---|
| Hack Regular | `Hack-Regular.txt` (MIT, and the Bitstream Vera licence) |
| Noto Emoji Regular | `OFL.txt` (SIL Open Font License 1.1) |
| Ubuntu Light | `UFL.txt` (Ubuntu Font Licence 1.0) |
| emoji-icon-font | `emoji-icon-font-mit-license.txt` (MIT) |
