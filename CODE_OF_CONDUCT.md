# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work.
Harassment of any kind is not accepted.

bugsweep is a privacy and safety tool. Do not use the issue tracker or pull
requests to help anyone track, film or record another person without consent.

To report a problem, open a
[private security advisory](https://github.com/danjdewhurst/bugsweep/security/advisories/new)
or contact the maintainer through their GitHub profile. Reports are kept
confidential.
